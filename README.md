# MirrorBackup

Windows 上的增減量（鏡像）備份工具：可設定多組 src／dest 目錄，讓每一組的 **dest** 與 **src** 完全相同。
執行前會先列出每一組的差異，經你同意才動手，完成後產出執行結果報告。

## 需求

- Windows 10／11
- Python 3.8 以上（只用標準函式庫，不用另外安裝套件），並已加入 PATH

## 檔案

| 檔案 | 用途 |
|---|---|
| `run_backup.bat` | 雙擊執行 |
| `mirror_backup.py` | 主程式 |
| `backup.ini` | 設定檔：各組 src／dest、報告存放位置 |
| `reports\` | 執行結果報告（第一次執行後自動建立） |

## 設定

編輯 `backup.ini`。路徑直接寫，不用跳脫反斜線，也不用加引號；`;` 開頭的行是註解。

```ini
[settings]
report_dir = reports

[文件]
src = D:\Documents
dest = E:\Backup\Documents

[照片]
src = D:\Photos
dest = E:\Backup\Photos
```

- **`[settings]`**：共用設定，可省略

  | 欄位 | 說明 |
  |---|---|
  | `report_dir` | 報告存放位置，可省略（預設 `reports`）。相對路徑以程式所在資料夾為準；不可放在任何一組的 dest 裡面 |

- **其他每個區段是一組備份目錄**，`[ ]` 裡是組名（自己取，console 與報告用它標示），組數不限

  | 欄位 | 說明 |
  |---|---|
  | `src` | 備份的正本 |
  | `dest` | 備份目的地，不存在會自動建立。**執行後 src 沒有的東西會從這裡刪除** |

### 設定檢查

**整份拒絕執行**（會讓組與組互相干擾，或一定會出錯）：

- 同一組的 src 與 dest 相同或互相包含
- 兩組的 dest 相同或互相包含（兩組會互刪對方的檔案）
- 某一組的 dest 與另一組的 src 相同或互相包含（結果會隨執行順序而不同）
- report_dir 放在某一組的 dest 裡面
- 寫了不認得的欄位（例如把 `dest` 打成 `dset`）、組名重複、沒有任何一組

**只略過那一組、其他組照常**（例如隨身碟沒插）：

- src 資料夾不存在
- dest 已存在但不是資料夾

不同組的 src 可以相同或互相包含，例如同一份資料備份到兩顆硬碟。

## 執行

雙擊 `run_backup.bat`，或在命令列執行：

```
python mirror_backup.py
python mirror_backup.py --config 其他設定檔.ini
```

`run_backup.bat` 也能帶參數：`run_backup.bat --config 其他設定檔.ini`。

### 流程

1. **逐組掃描並列出差異**：每一組先列出 src／dest 的檔案數、資料夾數與總大小，再列出差異清單

   | 標記 | 意思 |
   |---|---|
   | `[+] 新增` | src 有、dest 沒有的檔案 |
   | `[*] 更新` | 兩邊都有但大小或修改時間不同（括號內附原因） |
   | `[~] 改大小寫` | 同一個檔案或資料夾，只有名稱大小寫不同 |
   | `[+] 新增資料夾` | src 有、dest 沒有的資料夾（含空資料夾） |
   | `[-] 刪除` | dest 有、src 沒有的檔案 |
   | `[-] 刪除資料夾` | dest 有、src 沒有的資料夾 |

2. **總覽**：每組一行，列出相同／略過，或新增、更新、刪除幾個檔
3. **確認**：一次確認所有有差異的組別。輸入 `y` 才執行，其他任何輸入都會取消、不做任何變更
4. **逐組執行**：每一組依序刪除多餘檔案 → 刪除多餘資料夾 → 改大小寫 → 建立資料夾 → 複製新增與更新的檔案
5. **驗證**：每一組執行完重新比對 src 與 dest，確認是否完全相同
6. **報告**：所有組別寫在同一份 `reports\backup_report_YYYYMMDD_HHMMSS.txt`

所有組別都已相同（或被略過）時不會詢問、不產生報告。

執行到一半按 `Ctrl+C` 會停止目前這組，後面的組別不執行，並產出到目前為止的報告。

### 報告內容

- 開始／結束時間、耗時、整體結果、合計複製資料量
- **各組結果**一覽：成功／相同，不需備份／部分失敗／中斷／驗證仍有差異／未執行／略過（附原因）
- 每一組的明細：
  - 各類動作的預計、成功、失敗件數，以及實際複製的資料量
  - 驗證結果：完全相同，或列出剩下的差異
  - 失敗項目與原因、src 讀取錯誤、保留未刪的項目、略過的連結
  - 每一個動作的執行明細

## 判定規則與注意事項

- **比對方式**：以「檔案大小＋修改時間」判斷是否相同，不讀取內容比對。修改時間容許 2 秒誤差，以相容 FAT／exFAT 隨身碟
- **刪除不經過資源回收筒**：dest 裡多出來的檔案會直接刪除
- **src 是空的**而 dest 有檔案時會特別警告，避免路徑填錯把 dest 清空
- **路徑比對不分大小寫**（同 Windows 檔案系統）；只有大小寫不同時，把 dest 改名成 src 的寫法
- **符號連結與 junction 一律略過**，不備份也不刪除，避免順著連結動到其他位置
- **src 讀不到的資料夾或檔案**（例如權限不足）：dest 對應位置的內容保留不刪，並列在報告裡
- **唯讀檔**可以正常覆蓋與刪除；**超過 260 字元的長路徑**也能處理
- **複製時先寫暫存檔（`.mbtmp`）再替換**，中途失敗不會留下半個檔案蓋掉舊版
- **資料夾本身的修改時間不比對**；檔案會連同修改時間、屬性（唯讀、隱藏）與替代資料流一起複製，權限設定（ACL）不複製

## 結束代碼

| 代碼 | 意思 |
|---|---|
| 0 | 全部成功、已取消，或所有組別本來就相同 |
| 1 | 有組別執行失敗、被中斷、驗證後仍有差異，或因設定問題被略過 |
| 2 | 設定檔錯誤（整份拒絕執行） |
